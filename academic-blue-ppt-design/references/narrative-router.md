# 科研叙事路由

先明确受众与沟通目标，再组织章节。章论点和正文结论必须来自本次材料。

| 场景 | 常见推进关系 |
|---|---|
| 文献综述、研究进展 | 对象与意义、性质或分类、机制与证据、研究分歧、结论与后续问题 |
| 项目申请 | 需求、缺口、科学问题、研究内容、方法与验证、创新、基础与风险 |
| 项目结题 | 任务基线、指标对照、成果证据、偏差、资源、结论与后续 |
| 人才与职称 | 履历、职责、独立贡献、成果证据、影响、未来工作与条件 |

这些是选择依据，不是固定章名或统一科学答案。文稿已有结构可作为起点，允许按论证重组，保留源段落映射。

每章记录核心问题、总论点、支撑内容和下一章衔接。每页承担一个主要任务，章内形成设问、证据与回答。报告总结回指已有证据，展望区分现有结论与待研究内容。

每个主要章节入口重复同一原生“汇报目录”，仅列各部分概括标题并高亮当前章。总目录与章节切换页使用相同位置、等间距与居中对齐；不追加章论点、章节介绍及其底框。章论点保存在规划中，由正文展开。封面不编造姓名、单位或Logo。全稿只有一套蓝白框架。
