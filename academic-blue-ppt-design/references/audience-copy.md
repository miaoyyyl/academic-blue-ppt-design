# 面向听众的展示文案

页面直接讲研究对象、机制、数据、结论及必要的科学条件。来源材料和制作判断是写作依据，不是额外的展示内容。

`sourceLabel`仅作为制作元数据保留，不渲染为内容页脚。通用汇报名及来源核验、验收说明小字从展示中移除；必要科学条件以正常字号并入对应正文，文献可集中在参考页。详见[组件展示检查](component-polish.md)。

- 顶部综述句末不加句号、逗号、分号、冒号、问号、叹号或省略号。仅清理综述末尾的句读，保留句中标点、小数点、缩写内句点、百分号、单位和必要的科学符号；普通正文使用正常标点。编译时自动规范综述及对应展示映射，直接原生操作与实际PPTX定稿检查拒绝综述末尾的句读。

- 不把“原文指出”“原图另列”“本页保留”“仍以‘可能’表述”等编辑口吻放在标题、总点、正文或图注。改成实际论述，如“过程A可能影响指标B”。具体作者与年份、文献编号和有助于理解图的缩写说明仍可使用。
- 不增加“解释边界”“证据边界”“共同边界”“口径对照”等验收标签或页脚说明条。已有说明块只承担制作解释时，删除整个块，包括底板和标签；仍有必要科学内容时，将其并入对应正文并以实际内容命名。
- 无法辨读、分类沿用、来源字段未解释、覆盖计数、没有额外核验等记录保存到独立QA文件。不要放进展示页或演讲备注。备注保留文献出处和有用的讲述补充。
- “可能”“潜在”“通常”“尚缺实证”、适用范围、单位、实验条件和比较基准影响结论时，保留在可见科学表述中。不得为了清理编辑口吻把假说改成事实、把检出改成因果，或把不同单位的数值合并排名。
- 原来写“原文未提供定量关系”，若定量关系的不确定性确实影响该页结论，可改成“该关系尚缺定量证据”。若只是记录本次提取能力，移到QA。来源缺字段时不编造数值；省略非必需字段，必要的数据矩阵可用“—”并按学术惯例说明。

规划时只检查将被渲染的`operations[].fields`；`sourceIds`、`pageTask`、选择理由和QA记录不进入展示。构建和定稿均检查真实PPTX的原生文字与表格文字，包括不在规划内的额外对象。图片内文字仍须在实际渲染中目视检查。

标准构建、直接原生构建和定稿已强制接入。也可单独运行：

```text
node scripts/audit_audience_copy.mjs --plan 规划.json --deck presentation.pptx --report audience-copy-audit.json
```

此检查定位明确的制作口吻，不执行自动删除或全文替换；必要的科学限定由制作者结合上下文保留。文件检查通过后，仍要连读标题、正文与图注，确认内容自然且没有空说明框。
