# 页面任务、补图与总述对齐

在选择组合之前判断模块的可视化任务；空间居中只能处理位置，不能证明内容足以独立成页。

## 规划字段

新稿使用 `figurePolicy.version:2`、`visualPolicy.version:2`和`leadPolicy.version:1`。每个正文模块提供 `visualIntent`：

| visualIntent | 图片任务 | 优先类型 |
|---|---|---|
| application | 说明实际用途、设备或作业环境 | scene、object |
| mechanism | 解释路径、界面或转化 | mechanism |
| phenomenon | 展示现象、主体或外观差异 | phenomenon、scene |
| data | 支撑比较、趋势和量化结果 | data |
| context | 定位场景或识别对象，不能充当效果证据 | scene、object、phenomenon |

`mixed` 图的每项 readingTargets 还需 `visualIntent`，并包含与所绑定模块一致的区域。原图也接受任务检查：应用介绍不能仅配反应式；不能为已有原图反过来修改页面任务。asset-manifest登记 `figure_type`，图的声明不得与已登记类型相矛盾。原始混合图允许选择与命题相关的子区域；完整原资产仍保留。

## 选型与稀疏复核

- 主图旁解释默认 `treatment:'tab'`：横向圆角蓝标题，正文使用整栏宽度。显式左标签若正文净宽低于340px立即失败；加宽文字栏或换结构，不缩字。宽标签行仍按内容使用。
- 正文自然高度不足可用高度60%时，无论有无图片均登记稀疏复核。无有效图仍触发`SPARSE_CONTENT_REQUIRES_VISUAL_OR_MERGE`；独立文字/关系栏不足60%另触发`LOCAL_REGION_CONTENT_TOO_SPARSE`。图片不能解除文字栏问题。60%用于发现问题，不是填满配额；相关主图与解释已按首尾边界绑定时，应核对主图阅读任务，而不强行增字。
- 先按任务策划现象图、数据图、原理图或应用图；独立图用同层图文栏，共享图用上文下图。补图后仍不足以独立讲述时，合并相邻同主题页。60%只是复核触发值，不是必须填满的面积配额。
- 图片需明确绑定命题并达到有效尺寸；小图标、重复同图充数及无关装饰不能处理稀疏问题。总览到细节、正文到总结的必要重复，应说明对应的命题和用途。

## 总述与正文

规划thesis仍记录本页判断；它不要求额外显示一次。新稿逐页设置`lead:{mode:'none'}`或`lead:{mode:'shared',text,component,covers,reason}`；`transition`仅用于确有转折引领作用的情况。shared须覆盖至少两个模块，文字不能重复页头。

可选component为gradient（渐隐带）、plain（浅底判断带）、capsule（蓝底白字圆角条）、outline（细框判断）。全部复用已授权原生对象，语义角色独立于组件名与槽位。无lead时正文默认从110px开始，有lead时从177px开始；不能只删文字而保留空槽。显示的lead在正文宽度居中、句末无句读，普通解释左上对齐。实际PPTX核对角色对应的真实槽位、文字及对齐。

## 补图与验收

优先检索可追溯真实图片，记录来源页、图片URL、署名、用途、尺寸和SHA。必要时生成定性示意，保留提示词并明确标“示意”；不生成数据或实验效果。来源署名短注上屏，完整来源进入备注和素材清单。图片与原生正文保持独立、等比，可恢复裁切。

推荐、编译、build与finalize共用 `assets/visual-policy.mjs`。旧几何接口可以读取，但缺失的模块任务会在完整构建检查中要求补齐；低版本字段不能关闭检查。组合中性样例用于几何和容量测试，不等于独立页面已获视觉验收。

逐页查看实际PowerPoint渲染，确认图片确实表达所述对象和过程、文字没有重复解释整张图、图像没有被压到不可辨认。程序不能仅凭类型字段完成语义判断。

组织参考：微塑料人工稿第4/8页的上文下图和实物图；镉污染修复人工稿第15/16页的居中总点和应用现场；高光谱模板第7页的圆角专题标题；太赫兹模板第16页的短说明与设备图组。只迁移组织方法，不迁移其数据或固定题材。
