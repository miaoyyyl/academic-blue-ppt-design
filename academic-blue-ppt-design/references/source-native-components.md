# 原生组件来源与允许修改

当前34个原生类型与变体。来源包括materials材料稿和明确授权的by_human人工稿，含左标签、原生符号、渐变总点、分类、括号、循环、两种表格及两种图框。具体来源、哈希、页码与对象ID见registry和类型JSON；组件数量不等于完整页面数量，也不表示全部材料页已经可调用。

圆形编号保留源accent6引用，在当前蓝白母板下由原主题的0B4FA1继承为0046A4；其余几何、组合、填充和线条仍保留原生XML。不得把这一主题继承说成原稿逐像素复刻。完整溯源记录和限制保存在类型JSON中。

新增12型跨多个主题：提取时读取原页→版式→母版→主题，按原主题把schemeClr解析为源RGB，同时保留透明度、亮度变换和渐变停止点。记录在themeResolution；这属于主题颜色冻结，不是重画样式。原生项目符号字体与悬挂缩进必须保留；正文用本次输入与当前字体对替换。组合中非视觉编辑标签及旧链接删除，不能遗留指向原稿的关系引用。

复制完整形状/组合及其原生几何、填充、线条、阴影、渐变和装饰依赖；主题与母版来自同一材料。清空原文本、来源身份、原科学图片、内部旧页链接和编辑标签。文字框保留，空内容仍需合法空段落。保留图片槽的形状样式，替换为本次登记图片并按原比例适配。

允许修改：内容、字体对、字号、位置、尺寸、同页重复组数量和目录激活状态。目录的激活/未激活样式均从原例复制；不能因内容更换而重画简单蓝框作为替代。

原生桥使用保留命名空间的 lxml 处理XML，避免重新命名破坏原生扩展与属性值中的QName。Artifact Tool承担本地JavaScript编排、页面与备注制作及正式SDK回读；原生桥负责源对象保真提交。PowerPoint实际打开、渲染和保存重开是独立检查。

实现参考了开源项目的模板复制、槽位绑定与分析/生成分层思路：[pptx-automizer](https://github.com/singerla/pptx-automizer)、[Presenton](https://github.com/presenton/presenton/blob/main/docs/template-v2.md)、[PPTAgent v0.2.0](https://github.com/icip-cas/PPTAgent/tree/v0.2.0)。未引入外部模型服务，也未以第三方模板替代用户材料。
